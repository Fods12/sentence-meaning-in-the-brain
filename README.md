# Sentence Meaning in the Brain
Code to accompany the paper 'When word order matters: human brains represent sentence meaning differently from large language models'.

Code is organised as follows:
* Code-1-stimuli contains code for the preparation and presentation of the sentence stimuli.
* Code-2-preprocessing contains code for preprocessing fmri data.
* Code-3-GLMSingle contains code for GLMSingle and RSA analysis of fmri data.
* The jupyter notebooks in the main directory are the drivers that perform analysis and visualisation of fmri and behavioural data.

Data is organised as follows:
* Data-fmri contains raw searchlight and similarity results for fmri data, as well as atlas templates.
* Data-behavioural contains Prolific survey behavioural data and task responses from all fmri participants.
* Data-models contains embeddings, parses, and sentence similarities for all assessed computational models.
* Data-physio contains respiratory and heartrate data for all fmri participants.

Sentence stimuli and questions answered by participants can be found in the main directory.
